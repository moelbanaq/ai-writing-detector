# Privacy Policy & Document Retention

1. **Stateless Processing**: The AI Writing Forensic Analyzer performs in-memory analysis of text.
2. **Zero Default Storage**: Submitted documents and extracted text are NEVER saved to disk or persistent databases by default.
3. **No External API Leakage**: Analysis is performed entirely on local compute nodes without calling third-party commercial AI detection endpoints or cloud LLMs.
4. **No Sensitive Logging**: Server logs record request metadata (timestamps, content length, status codes) but NEVER log raw document text or sensitive payloads.
